# ☁️ AWS Cloud Infrastructure & Labs

Repositorio dedicado a documentar arquitecturas, scripts de automatización, despliegues y laboratorios prácticos realizados en Amazon Web Services (AWS).

---

## 🛠️ Tecnologías y Servicios Utilizados
* **Compute:** Amazon EC2, AWS Lambda
* **Storage & Database:** Amazon S3, Amazon RDS
* **Networking:** VPC, Subnets, Internet Gateways, Security Groups
* **Infrastructure as Code (IaC):** Terraform

---

## 📂 Estructura de Proyectos
1. `ec2-web-server/` - Despliegue de servidor web básico con Apache/Nginx en EC2.
2. `s3-static-website/` - Alojamiento de sitio web estático con control de políticas de acceso.
3. `terraform-aws-vpc/` - Creación de una red privada virtual (VPC) modular usando Terraform.

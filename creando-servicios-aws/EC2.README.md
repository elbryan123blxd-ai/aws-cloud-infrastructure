# Amazon EC2(introducción y configuraciones basicas)

> Servidores virtuales en la nube para alquilar potencia de cómputo, escalar de forma flexible y pagar exclusivamente por el tiempo de uso, eliminando la inversión en hardware físico.

---

## ⚡ Características Clave

* **Elasticidad:** Escalado horizontal y vertical según la demanda del sistema.
* **Modelo Pay-as-you-go:** Facturación exacta por segundo u hora de uso activo.
* **Aprovisionamiento Ágil:** Despliegue inmediato mediante consola, CLI o automatización (IaC).

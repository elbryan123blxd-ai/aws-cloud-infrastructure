# Amazon S3 Buckets

Un **bucket** (o cubo) es el contenedor fundamental en **Amazon S3** utilizado para almacenar todos tus archivos y carpetas en la nube de AWS. Piensa en él como una carpeta raíz o un disco duro virtual con capacidad de almacenamiento ilimitada.

## Características Clave

* **Nombres Únicos**: El nombre de cada bucket debe ser globalmente único en todo AWS y en todas las regiones.
* **Control de Acceso**: Permite configurar políticas de seguridad, permisos públicos o privados y controles de acceso a nivel de bucket u objeto.
* **Organización**: Los archivos dentro de un bucket se guardan como **objetos**, organizándose de manera lógica mediante prefijos y rutas virtuales.
* **Regiones**: Cada bucket se crea en una región geográfica específica de AWS para optimizar la latencia y cumplir con normativas de cumplimiento de datos.

## 🗄️ El archivo de estado (`terraform.tfstate`)

El archivo `terraform.tfstate` es la base de datos interna y el registro fundamental que utiliza Terraform para mantener una fotografía exacta de la infraestructura real desplegada en AWS.

### Puntos clave:
* **Mapa de recursos:** Relaciona el código que escribes en tus archivos `.tf` con los IDs reales de los recursos creados en la nube (como instancias EC2 o grupos de seguridad).
* **Control de diferencias:** Se consulta en cada ejecución (`plan` o `apply`) para determinar si Terraform debe crear, modificar o destruir recursos.
* **Buenas prácticas:** Contiene información crítica y datos sensibles, por lo que nunca debe editarse manualmente ni subirse a repositorios públicos de código.

## ¿Qué es la Importación?
La importación es el proceso de traer recursos ya creados en un proveedor de nube (ej. AWS) hacia el control de Terraform, permitiendo gestionarlos mediante código sin necesidad de destruirlos y volverlos a crear.

## Flujo de Trabajo

### 1. Vincular el Recurso
Usa el comando `import` para registrar el recurso existente en tu archivo de estado (`tfstate`):

```bash
terraform import <tipo_recurso>.<nombre_logico> <id_del_recurso>
```
